About This Project

This is my personal portfolio website. I designed and built it from scratch, without a template, so recruiters and hiring teams can see my work and what I can do in one place.

I’m a final-year Information Technology student at Universiti Geomatika Malaysia, and my interests are cybersecurity and web development. I wanted a site that’s fast, simple to navigate, and works on any screen. Building it myself also gave me practice with the parts of front-end work that tutorials tend to skip, like layout planning, responsive design, and keeping the code clean and organised.

What it shows
Responsive layout: adapts to desktop, tablet, and mobile using [Flexbox / CSS Grid] and media queries
Single-page navigation: smooth scrolling between sections (About, Skills, Projects, Contact)
Clean, semantic HTML for accessibility and readability
[Interactive elements with vanilla JavaScript, e.g. mobile menu, scroll effects, contact form validation]
Projects section featuring my academic work, including my final-year project on secure cloud backup integrity
Built with

HTML5 · CSS3 · JavaScript · [Git & GitHub] · VS Code

What I learned

Planning a page before coding it, writing CSS that scales instead of patching problems one at a time, and testing on real devices. It’s a working site, and I keep improving it as I learn.
